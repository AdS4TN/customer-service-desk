# Cross-language reception extension

## Direction contract

THESIS: Read the customer's language and review an outgoing translation without losing the source draft.
OWN-WORLD: Preserve the existing neutral inbox, compact Base UI controls, Geist typography and Lucide icons.
STORY: The operator chooses a reading language, translates messages in place, writes a reply, and confirms the translated text before sending.
FIRST VIEWPORT: Keep the three inbox columns. Use a compact language strip; translations sit below the original message. Outgoing preview is a protected-focus dialog with source and editable translation stacked on narrow screens.
FORM: Ordinary local extension; no concept seed or visual-system change. Explicit preview confirmation is the signature interaction; asynchronous work never sends or overwrites a draft.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

No new imagery or design-system changes. Text messages only; no audio transcription or document translation is claimed. Existing customer data and channel connections remain untouched during tests.
