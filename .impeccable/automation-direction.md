# Automation

Mode: Operate. Extend the existing AgentDesk dashboard, not a new visual identity.
User confirmed rule list, trigger/conditions/actions, audit, lead handling and tickets; disabled by default, no outbound messages.

## Direction contract

THESIS: Make business automation explicit and inspectable through rules and receipts, not an opaque AI capability switch.
OWN-WORLD: Inherit dashboard semantic tokens, compact system typography, unshadowed surfaces, rounded-md controls and Lucide icons.
STORY: Choose a template, configure conditions and actions, dry-test a sample, save a disabled draft, explicitly enable it, inspect results.
FIRST VIEWPORT: Compact rules and execution-record tabs above a filterable table; create action in the toolbar. Editor uses sequential unframed fieldsets with a fixed save footer.
FORM: User-confirmed rules/conditions/actions form, code-led extension; no concept seed needed for the specified structure.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Existing design is preserved; no new system or shipping raster is required. Public reference: https://mixdesk.com/help/docs/automated-configuration/ . Authenticated Mixdesk UI was unavailable because browser connection rejected the current authentication method.
